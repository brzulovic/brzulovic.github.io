OpenFox: A Powerful Local-LLM-First Agentic Coding Assistant

August 23, 2026 2 min read
#OpenFox #Local-LLM #Coding-Agent #Developer-Productivity #Automation

Overview

OpenFox is an autonomous coding agent built specifically for local LLMs, designed to provide a comprehensive development environment right out of the box. By leveraging a contract-driven execution pipeline, it ensures that your code meets specific acceptance criteria, creating a reliable loop for automated software development.

Quick Start

Getting started with OpenFox is straightforward. Ensure you have Node.js (>= 24.0.0) installed, then install the package globally:

npm i -g openfox
openfox

On the first run, OpenFox will automatically detect your local LLM backend—supporting vLLM, sglang, ollama, and llamacpp—and configure itself accordingly.

Key Features of Version 2.0

The 2.0 release brings significant improvements to the agentic workflow:

  • Multi-Turn Agent Engine: A completely rewritten agent loop that utilizes EventStore as a single source of truth, unifying all modes like planning, building, and verifying.
  • Provider Dialog: A comprehensive UI for configuring providers, including reasoning efforts and profile management.
  • Unified Image Handling: Automatic vision model fallback allows any model to process images by generating descriptions before each turn.
  • Safe File Editing: A per-file mutex system prevents race conditions during parallel edits.
  • Enhanced Workflows: Support for workflow sub-groups and a dedicated code review phase.

CLI Commands & Options

You can manage your development environment directly from the terminal:

Option Description Default
-p, --port <number> Specify server port 10369
--no-browser Don’t open browser on start Opens browser
-h, --help Show help message -
-v, --version Show version number -

Common commands include:

# Start server for current project
openfox

# Manage LLM providers
openfox provider add
openfox provider list

# Show current configuration
openfox config

Extensibility via Plugins

OpenFox allows for modular functionality via plugins. You can add support for various services by installing plugins in your configuration directory:

  • ChatGPT Plus/Pro: openfox-chatgpt
  • Github Copilot: openfox-github-copilot
  • Google Antigravity: openfox-google-antigravity
  • xAI SuperGrok: openfox-xai-supergrok

Environment Configuration

OpenFox provides granular control through environment variables. Key variables include:

  • OPENFOX_LLM_URL: Set the API base URL (default: http://localhost:8000/v1).
  • OPENFOX_MAX_CONTEXT: Defines the maximum context window (default: 200000).
  • OPENFOX_DB_PATH: The path to the SQLite database used for session storage.

Note: Always ensure your backend LLM is compatible with the OpenAI API format to ensure full integration with OpenFox’s features.
