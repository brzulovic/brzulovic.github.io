🇫🇷 Version Française

Le concept de “second cerveau” peut sembler complexe, mais il s’agit essentiellement d’un ensemble de fichiers texte organisés, gérés par un fichier index qui guide l’IA. Pas besoin d’Obsidian ou de bases de données propriétaires ; tout repose sur du Markdown pur sur votre disque.

Pourquoi les fichiers plats plutôt que les applications ?

Les applications imposent souvent des formats propriétaires qui créent des frictions pour les agents IA. En utilisant du Markdown brut, vous garantissez une lisibilité maximale pour l’IA.

La structure recommandée

Utilisez trois dossiers principaux :

  • notes/ : Entrées spécifiques à un sujet.
  • people/ : Fiches de contacts ou entreprises.
  • projects/ : État d’avancement de vos projets actuels.

Le rôle du fichier CLAUDE.md

Ce fichier est le système nerveux de votre second cerveau. Placé à la racine, il indique à l’agent comment interpréter votre structure. Si vous utilisez Claude Code, ce fichier est automatiquement chargé dans le prompt système.

# Guide de navigation
- @MEMORY.md : Contexte global
- @projects/ : Projets actifs
- @notes/ : Base de connaissances

🇬🇧 English Version

Building a “second brain” doesn’t require complex software. It is simply a collection of flat .md files organized in folders, managed by a single CLAUDE.md index file that acts as a compass for your AI agent.

The Principle: Flat Files Over Apps

Proprietary apps often create friction. An AI agent performs best when it can read plain text files directly from your disk without intermediate layers. Flat Markdown is accessible, universal, and perfectly readable by any agent.

Recommended Directory Skeleton

  • notes/: Topic-specific entries. Keep one topic per file.
  • people/: Cards for contacts, companies, or meeting notes.
  • projects/: Current status, paused work, and next steps.

CLAUDE.md: The Map

This file is the nervous system of your setup. It tells the agent how to navigate your files. By using CLAUDE.md at the root, tools like Claude Code automatically ingest your custom instructions and context on startup.

Pro-Tip: Leveraging @-Connections

Reference your core files directly in the index using @ paths to ensure the agent keeps your critical context in its active memory.
